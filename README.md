# حمل معاء عبود — Abd Video Downloader

موقع عربي (RTL) بتجربة ثلاثية الأبعاد متحركة لتنزيل الفيديو من روابط المنصات: صفحة ترحيب سريعة، ثم صفحة تحميل
تُرسل الرابط إلى الخادم، ويُعاد الملف للمستخدم مباشرةً كـ MP4 / WEBM / صوت M4A
عبر رأس `Content-Disposition: attachment` — بدون صفحات وسيطة.

## المزايا
- **أقل من ثانيتين**: Next.js App Router + Tailwind، خطوط عربية مستضافة ذاتياً عبر `next/font`، وخلفية Canvas خفيفة.
- **محرك استخراج**: `yt-dlp` (أكثر من 1000 موقع) مع كشف تلقائي للروابط المباشرة.
- **بدون تخزين للفيديو**: يمرّ الملف كبث (stream) مع دعم `Range` للمعاينة، ولا يُكتب على القرص.
- **حالة شفافة**: كل محاولة تُسجَّل في PostgreSQL مع سبب الفشل بالعربية، وسجل مباشر للأرقام.
- **حماية**: تحقق من صحة الروابط، منع عناوين الشبكة المحلية (SSRF)، حد أقصى 300MB، وتحديد 12 طلباً/دقيقة لكل IP.
- **حدود صريحة**: الجودة تعتمد على ما تسمح به المنصة؛ بعض المنصات تحجب خوادم الاستضافة وتحتاج كوكيز.

## التشغيل محلياً
```bash
npm install
# DATABASE_URL في .env
npx drizzle-kit push
npm run dev
```

محرك الاستخراج (اختياري لكنه مطلوب لروابط المنصات):
```bash
pip install -U yt-dlp
# أو: YTDLP_PATH=/path/to/yt-dlp
```
الروابط المباشرة (`mp4` / `webm` / `mp3`) تعمل بدون `yt-dlp`.


## الطبقة الحركية ثلاثية الأبعاد
- **شاشة بداية**: شعار سحابة وسهم تنزيل متحرك + «حمل معاء عبود»، تظهر مرة واحدة لكل جلسة (`sessionStorage`) ولا تظهر عند التنقل الداخلي.
- **شخصية عبود**: SVG rig بحركات تنفّس/إيماء رأس/ذراعين/وميض عينين، تستجيب لمؤشر الفأرة في 3D، وتعرض حقل الرابط الحقيقي وزر التحميل.
- **عمق 3D**: `perspective` + `preserve-3d`، شرائح `translateZ`، أيقونات منصات عائمة، توهج نيون دوّار حول الأزرار (`glow-button`).
- **حركة عند التمرير**: `Reveal` عبر `IntersectionObserver`، و`Tilt` لبطاقات تتمايل مع المؤشر.
- **مؤشر تقدم حقيقي**: عند الضغط على «تنزيل الآن» تُقرأ بيانات البث عبر `ReadableStream` ويُعرض النسبة الفعلية قبل حفظ الملف.
- **أداء وبطارية**: كل التأثيرات CSS transform/opacity، تُوقف الحركة عند إخفاء التبويب (`visibilitychange`)، ولا تعمل حركات المؤشر على أجهزة اللمس.
- **تقليل الحركة**: احترام `prefers-reduced-motion` + زر تبديل يدوي محفوظ في `localStorage`.

## بدون حسابات
الموقع أداة تحميل فقط: **لا تسجيل دخول، ولا إنشاء حساب، ولا جداول مستخدمين**.
أي روابط قديمة إلى `/login` أو `/account` تُحوَّل تلقائياً إلى `/downloader`.
وظائف التحميل وقاعدة بيانات `downloads` تعمل كما هي تماماً.

## مسارات التحميل
| المسار | الوصف |
| --- | --- |
| `/` | صفحة الترحيب (تحويل تلقائي خلال 1.6 ثانية مع زر تخطي) |
| `/downloader` | الواجهة الكاملة: اللصق، الصيغة، النتيجة، السجل، الأسئلة |
| `POST /api/resolve` | يستخرج الملف ويسجّل العملية (`{ url, format }` أو `{ sample: true }`) |
| `GET /api/download/[id]` | بث الملف كتنزيل (أو `?inline=1` للمعاينة) |
| `GET /api/jobs` | آخر العمليات |
| `GET /api/stats` | أرقام الخادم وحالة المحرك |
| `GET /api/health` | فحص الاتصال بقاعدة البيانات |

## قاعدة البيانات
جدول `downloads` (Drizzle ORM / PostgreSQL): بيانات المصدر والمنصة، الصيغة والجودة،
رابط الوسائط المؤقت ورؤوسه، الحالة وسبب الفشل، وعدّاد التنزيلات.
عند أول تشغيل تُزرع 3 عمليات «عيّنة» لاختبار الواجهة والتنزيل.


## الحصول على رابط دائم يعمل (Docker)
الرابط المؤقت لبيئة المعاينة محمي برمز وصول من المنصة (يعيد 403 لأي طلب خارجي).
لتشغيل الموقع برابطك الخاص على جهازك أو خادمك:

```bash
docker compose up -d --build
# ثم افتح: http://localhost:8080
```
- `db`: PostgreSQL 16 مع مخطط `downloads` يُنشأ تلقائياً من `docker/initdb/01-schema.sql`.
- `app`: Next.js + `yt-dlp` + `ffmpeg` مثبّتان داخل الحاوية، فتعمل روابط المنصات مباشرةً.
- فحص الصحة: `curl http://localhost:8080/api/health` → `{"ok":true}`.
- على خادم عام: وجّه نطاقك إلى الخادم، ثم `APP_PORT=80 docker compose up -d --build` أو ضع Caddy/Nginx أمام المنفذ 8080 لشهادة HTTPS تلقائية.

بدون Docker: `npm install && npx drizzle-kit push && npm run build && npm start` ثم `http://localhost:3000`.

## ملاحظات قانونية
الأداة للاستخدام الشخصي على محتوى تملكه أو لديك إذن بتنزيله. تحميل المحتوى يخضع
لشروط خدمة كل منصة وقوانين حقوق النشر (DMCA وغيرها). لا يخزّن الموقع ملفات الفيديو،
ولا يتجاوز أي إجراءات حماية للمحتوى المدفوع أو الخاص.
